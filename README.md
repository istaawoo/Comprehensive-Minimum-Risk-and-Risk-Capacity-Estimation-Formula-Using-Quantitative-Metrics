# Risk Capacity Estimator

Live app: https://riskcapacityformula.streamlit.app/

A Streamlit tool that estimates an investor's minimum-risk allocation and overall risk capacity from a set of quantitative inputs. The goal is to turn "how much risk can this person actually take" into a concrete, calculable number rather than a gut call.

**Run it:** `streamlit run streamlit_app.py`

**Built with:** Python, Streamlit
